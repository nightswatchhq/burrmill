# Experiment A4: how many plan shapes does a real workload produce? (roadmap 4.1)
#
# Sample: every views/*.sql across every nest on this machine. 126 files, 65 statements.
# Classified two ways, because A4's question gets a different answer depending on what you
# mean by 'shape', and reporting only the flattering one would be the day's fifth measurement
# fault:
#
#   DISTINCT SHAPES - the exact feature set, including which aggregates and whether there is
#     a cast. The pessimistic bound.
#   PLAN FAMILIES - the same statements with the aggregate mix collapsed to 'agg' and
#     expression-level features dropped, because a grouped aggregate with k accumulators is
#     one operator parameterised by k, not k operators. The optimistic bound.
#
# The coverage ratio is computed by handing every statement to burrmill::plan::plan - the real
# planner, not a model of it, which could drift.
#
# Reproduce: cargo run -p burrmill-bench --release -- shapes ~/Projects
# 2026-08-31T13:55:24Z
